# Demo Assets

Thư mục này chứa ảnh demo thực tế của ứng dụng:
- `demo_input.jpg`: Ảnh PCB gốc dùng làm đầu vào.
- `demo_output.png`: Ảnh kết quả sau khi mô hình YOLO26n phát hiện linh kiện (bounding boxes).
- `screenshot_detect_preview.png`: Ảnh chụp giao diện nhận diện (ảnh gốc song song với ảnh kết quả, kèm các thẻ metrics thời gian & số lượng).
- `screenshot_detect_details.png`: Ảnh chụp giao diện thống kê tổng hợp số lượng linh kiện và bảng chi tiết độ tin cậy, kích thước, tọa độ.
